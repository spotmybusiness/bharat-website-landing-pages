## 1. Overview & Methodology

This document maps the search intent, target keywords/themes, geographic intent, and conversion intent for all 13 canonical routes of the Bharat Relocators website. Search intents are classified into four primary search engine categories:
- **Transactional**: User wants to purchase, book, or request a quote immediately.
- **Commercial Investigation**: User is comparing service providers, reviewing credentials, evaluating processes, and checking price ranges before making a decision.
- **Informational**: User is researching guidelines, packing requirements, documentation rules, or shifting procedures.
- **Navigational**: User is seeking a specific brand page, contact channel, or tracking utility.
